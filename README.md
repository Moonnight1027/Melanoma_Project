# Melanoma Skin Cancer Classification: Traditional CV vs. Deep Learning

## 📌 Project Overview
This project focuses on classifying medical skin lesion images into two categories: **Benign** and **Malignant**. It serves as a comprehensive comparative study between two different computer vision approaches:
1. **Traditional Machine Learning (ML):** Utilizes OpenCV for dynamic Field of View (FOV) Otsu masking and extracts 14-dimensional features (HSV color, GLCM texture, and Contour shapes). A Random Forest classifier is then trained on these manually engineered features.
2. **Deep Learning (DL):** Utilizes PyTorch and Transfer Learning with a pre-trained **ResNet18** model to automatically extract features and classify the images without the need for manual masking.

## 🛠️ Setup & Installation
1. Clone this repository or create the project folder.
2. Download the **SIIM-ISIC Melanoma - 256x256 images** dataset from Kaggle.
3. Place the `train/` folder and `train.csv` directly into the root of this project.
4. Install the required Python dependencies:
```bash
pip install opencv-python numpy pandas scikit-image scikit-learn matplotlib seaborn tqdm torch torchvision
```

## 🚀 Execution Workflow

### Step 1: Data Preparation
The original dataset is highly imbalanced (approx. 98% benign). Run this script to under-sample the benign class and create a balanced 1:1 dataset in the `./dataset/` directory.
```bash
python prepare_data.py
```

### Step 2: Traditional Machine Learning Pipeline
You can run the entire ML pipeline (Feature Extraction -> Training -> Prediction) automatically using the provided batch script:
```bash
python run_pipeline.py
```
**Or run them step-by-step manually:**
1. **Feature Extraction:** Generates `X_features.npy` and `y_labels.npy` in the `./data/` folder.
   ```bash
   python ext.py
   ```
2. **Model Training:** Splits data into Train (70%), Validation (15%), and Test (15%). Trains the Random Forest model and saves it.
   ```bash
   python train.py
   ```
3. **Inference (Prediction):** Add a few `.jpg` images to the `./test/` folder, then run:
   ```bash
   python predict.py
   ```
   *(Check the `./result/` folder for visual outputs of the dynamic masks and predictions).*

### Step 3: Deep Learning Pipeline (Comparison)
Train the ResNet18 model using PyTorch to compare the performance with the traditional ML approach.
1. **Train ResNet18:**
   ```bash
   python train_dl.py
   ```
2. **DL Inference (Prediction):**
   ```bash
   python predict_dl.py
   ```

## 📊 Evaluation & Results
* **Data Split Strategy:** The dataset is rigorously split into Training (70%), Validation (15%), and Testing (15%) to prevent data leakage and ensure fair evaluation.
* **Outputs:** 
  * Training scripts generate a **Confusion Matrix** in the `./result/` folder.
  * Prediction scripts generate a side-by-side comparison of the original image and the Region of Interest (ROI) mask, along with the model's confidence score.
