# Melanoma Skin Cancer Classification: Traditional CV vs. Deep Learning

## 📌 Project Overview
This project classifies dermoscopic skin lesion images as **Benign** or **Malignant** and compares two approaches:
1. **Traditional Machine Learning (ML):** OpenCV lesion segmentation (Otsu on valid skin pixels only, morphology, largest contour) followed by 14 handcrafted features (6 HSV color, 5 GLCM texture, 3 shape). An **XGBoost** classifier, tuned with patient-grouped 5-fold `GridSearchCV`, is trained on the standardized features, and **SHAP** explains each feature's contribution.
2. **Deep Learning (DL):** PyTorch transfer learning with an ImageNet-pretrained **ResNet18**, random flips / ±20° rotation, Adam, `ReduceLROnPlateau` and best-validation checkpointing.

Both pipelines use the same cleaned dataset (FOV masking + DullRazor hair removal), split by patient so that no patient appears in more than one of train / val / test. All inference scripts import the training-time preprocessing, so training and inference see identical inputs.

## 🛠️ Setup & Installation
1. Download the **SIIM-ISIC Melanoma 256x256** dataset from Kaggle:
   https://www.kaggle.com/datasets/cdeotte/jpeg-melanoma-256x256
2. Place the `train/` folder and `train.csv` in the project root.
3. Install the dependencies:
```bash
pip install -r requirements.txt
```

The trained models in `model/` are included, so `predict.py` and `predict_dl.py` run without the Kaggle images. Steps 1–3 (retraining) need `train/`.

## 🚀 Execution Workflow

### Step 1: Data Preparation
The original dataset has 33,126 images and is about 98% benign. `prepare_data.py` under-samples the benign class to a 1:1 ratio (1,168 images), splits it into Train/Val/Test (814 / 177 / 177) and cleans every image:
- **Patient-grouped split:** `StratifiedGroupKFold` (20 folds, grouped by `patient_id`, stratified by label) assigns 3 folds to test, 3 to val and 14 to train. Many patients have several lesions with the same skin tone and imaging conditions; a per-image split would put 44% of the test images next to a training image of the same patient and inflate the test score.
- **FOV masking:** pixels brighter than 240 (white background / glare) are set to black.
- **DullRazor:** Black-Hat transform detects hairs, which are then inpainted (Telea).

`dataset/` is deleted and rebuilt on every run.

```bash
python prepare_data.py
```

### Step 2: Traditional ML Pipeline
1. **Feature extraction** (`./data/X_*.npy`, `y_*.npy`, `ids_*.npy`): grayscale, 15x15 Gaussian blur, Otsu threshold computed on non-black skin pixels only, opening / closing, largest contour as the lesion mask, then 14 features. The GLCM only counts pixel pairs inside the lesion; the background is excluded so it does not dominate the texture features.
   ```bash
   python ext.py
   ```
2. **Training:** `StandardScaler` + XGBoost tuned by `GridSearchCV` (`n_estimators`, `max_depth`, `learning_rate`) on train + val, with patient-grouped 5-fold CV and ROC AUC as the score. Saves the confusion matrix, ROC curve and SHAP summary to `./result/`.
   ```bash
   python train.py
   ```
3. **Inference:** put a few raw `.jpg` images in `./test/` (FOV masking and DullRazor are applied automatically), then run it. Each result is saved as `./result/xgb_pred_<image>.png`.
   ```bash
   python predict.py
   ```

### Step 3: Deep Learning Pipeline
```bash
python train_dl.py      # ResNet18, 15 epochs, fixed seed, saves the best-validation weights
python predict_dl.py    # saves ./result/dl_pred_<image>.png
```

`python run_pipeline.py` runs Steps 1–3 training in order (prepare_data → ext → train → train_dl) and stops at the first failure.

## 📊 Results (patient-grouped test set, 177 images, threshold 0.5)
| Model | Test Accuracy | AUC |
|---|---|---|
| XGBoost (14 handcrafted features) | 77.40% | 0.8620 |
| ResNet18 (transfer learning) | 83.05% | 0.8547 |

The two AUCs are within noise of each other: with 177 test images the AUC uncertainty is roughly ±0.05. ResNet18 has the higher accuracy at the default 0.5 threshold. The validation set is also small, so ResNet18's validation accuracy moves between 66% and 74% from epoch to epoch.

These numbers are not directly comparable with the earlier per-image split (72.73% / 0.7743 and 72.73% / 0.8129), because the test set is different.

SHAP shows that brighter lesions (high `HSV_V_Mean`) push the prediction toward benign, while irregular shapes (low `Solidity`) and uneven brightness (high `HSV_V_Std`) push it toward malignant.
